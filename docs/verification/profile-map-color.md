# 프로필별 지도 색상과 방문 지역 검증

프로필 관리에서 선택한 색상은 해당 프로필에만 저장되고 방문 지역의 다섯 단계 농도에 적용된다. 미방문 지역과 경계선 색상은 변경하지 않는다. 기존 프로필은 분홍을 기본값으로 사용한다.

여행을 마칠 때 도착 목적지의 좌표를 앱에 포함된 시·군·구 경계와 비교하고 좌표와 지역 코드를 여행 기록에 저장한다. 같은 지역의 목적지에 여러 번 도착하면 목적지마다 한 번씩 집계한다. 위치를 알 수 없거나 지역을 확정할 수 없는 기록은 저장하되 지도 집계에서 제외한다. 경계 데이터 로드에 실패해도 여행 기록은 저장된다.

기존 기록 중 좌표가 저장된 방문은 해당 좌표로 지역을 판별해 집계하며, 좌표가 없는 방문은 집계하지 않는다. 앱의 경계 데이터는 지도 표시용으로 단순화되어 있어 경계선·섬 주변 결과가 실제 행정구역과 다를 수 있다. 실제 SDK 도착 이벤트 검증은 순정 내비게이션 에뮬레이터의 모의 주행 제약이 있으므로 아래 데모 재현과 구분한다.

## 검증

- `:app:ktlintCheck`, `:app:testDebugUnitTest`, `:app:compileDebugAndroidTestKotlin`, `:app:assembleDebug`, `:app:assembleDemo`를 실행한다.
- `ProfileMapMigrationTest`, `ProfileMapColorTest`, `ProfileStorageTest`, `VisitMapColorTest`, `VisitMapStorageIntegrationTest`를 Pleos 에뮬레이터에서 실행한다. 실제 경계 데이터와 Room 저장을 사용해 방문 전후 집계, 반복 방문, 위치 누락, 프로필별 분리와 마이그레이션을 확인한다.
- Pleos 데모 앱에서 실제 내비게이션 목적지를 설정하고 `도착 재현` 후 여행을 마친다. 같은 프로필의 지도를 열어 해당 지역이 선택한 색상으로 표시되는지 확인한다. 도착 재현은 실제 SDK 도착 이벤트를 발생시키지 않는다.

2026-11-14 Pleos Connect 2.1.0 에뮬레이터에서 전용 테스트 프로필로 파랑을 선택한 뒤 성심당 DCC점 목적지의 도착을 재현하고 여행을 저장했다. 지도에서 대전 지역의 연한 파랑 표시와 여행 기록을 확인했으며, 앱 재실행 후에도 선택색이 유지됐다. 검증용 프로필은 삭제했다.
